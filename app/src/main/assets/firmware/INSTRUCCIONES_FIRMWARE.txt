======================================================================
GUÍA DE FIRMWARE Y CONEXIÓN DE HARDWARE - TECLADO BIOS ARDUINO V1 & V2
======================================================================

DESCRIPCIÓN:
Este paquete contiene los códigos fuente (.ino) y binarios compilados (.hex)
para convertir un Arduino UNO en un Teclado HID + Ratón Low-Speed USB
compatible con cualquier BIOS / UEFI, Menú de Arranque (Boot Menu), GRUB,
Windows, Linux y macOS.

ARCHIVOS INCLUIDOS:
1. arduino_bios_keyboard_v2.ino: Firmware versión 2 con soporte para Teclado
   BIOS, modo texto libre y Ratón USB (Touchpad UEFI con clicks L, M, R).
2. arduino_bios_keyboard_v1.ino / .hex: Firmware versión 1 estable de teclado
   completo y ráfaga de teclas BIOS (DEL, F2, F11, F12, F10).
3. arduino_bios_keyboard_v0.ino / .hex: Firmware versión inicial de diagnóstico.

CIRCUITO DE CONEXIÓN USB DEL ARDUINO UNO A LA PC:
El Arduino Uno utiliza la librería V-USB para comunicarse directamente como
dispositivo HID con la PC anfitriona a través de sus pines digitales:

- Pin D2  del Arduino -> Resistencia 68 ohmios -> Cable D+ (Verde del USB PC)
- Pin D4  del Arduino -> Resistencia 68 ohmios -> Cable D- (Blanco del USB PC)
- Resistencia 1.5k ohmios entre Cable D- (Blanco) y 3.3V (o Pin D5 configurado en HIGH)
- Diodos Zener de 3.6V (o 3.3V) entre D+ y GND, y entre D- y GND (para fijar nivel lógico a 3.3V)
- Pin GND del Arduino -> Cable GND (Negro del USB PC)
- Pin 5V  del Arduino -> Cable VBUS 5V (Rojo del USB PC) - Opcional si se alimenta por USB

CONEXIÓN DEL ARDUINO AL TELÉFONO ANDROID:
- Conecte el puerto USB estándar del Arduino al teléfono Android mediante un cable/adaptador USB OTG.
- La aplicación "Teclado BIOS Arduino" detectará automáticamente el chip serial (CH340, CP2102, FTDI o Atmega16U2)
  a 9600 baudios, 8N1.

CÓMO FLASHEAR EL ARCHIVO .HEX EN EL ARDUINO:
Opción A: Desde la PC con Avrdude:
  avrdude -v -patmega328p -carduino -P /dev/ttyUSB0 -b 115200 -D -U flash:w:arduino_bios_keyboard_v1.hex:i

Opción B: Desde Arduino IDE:
  Abra arduino_bios_keyboard_v2.ino y presione "Subir" (Upload) en el puerto correspondiente.
