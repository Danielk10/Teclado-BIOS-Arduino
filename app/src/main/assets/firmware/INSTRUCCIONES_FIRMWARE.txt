======================================================================
GUÍA DE FIRMWARE Y CONEXIÓN DE HARDWARE - TECLADO BIOS ARDUINO V1 & V2
======================================================================

DESCRIPCIÓN:
Este paquete contiene los códigos fuente (.ino) y binarios compilados (.hex)
para convertir un Arduino UNO en un Teclado HID + Ratón Low-Speed USB
compatible con cualquier BIOS / UEFI, Menú de Arranque (Boot Menu), GRUB,
Windows, Linux y macOS.

ARCHIVOS INCLUIDOS:
1. arduino_bios_keyboard_v1.hex / .ino: (¡RECOMENDADO PARA ENTRAR A LA BIOS!)
   Firmware versión 1 puro USB HID Boot Keyboard. Es reconocido de inmediato
   por la BIOS / UEFI en el encendido en frío (POST) para pulsar SUPR/DEL, F2, F10, F12.
2. arduino_bios_keyboard_v2.hex / .ino: Firmware versión 2 compuesto (Teclado + Ratón
   UEFI). Para sistemas operativos (Windows, Linux, macOS) o UEFIs gráficas.
3. arduino_bios_keyboard_v0.hex / .ino: Firmware versión inicial de diagnóstico.

CIRCUITO DE CONEXIÓN USB DEL ARDUINO UNO A LA PC (ALIMENTADO A 5V):
El Arduino Uno se alimenta a 5V desde el teléfono vía cable OTG:

- Pin D2  del Arduino -> Resistencia 45-68 ohmios -> Cable D+ (Verde del USB PC)
- Pin D4  del Arduino -> Resistencia 45-68 ohmios -> Cable D- (Blanco del USB PC)
- Resistencia 1.5k ohmios entre Cable D- (Blanco) y PIN 5V del Arduino (o Pin D5 configurado en HIGH)
- Diodos Zener de 3.6V (o cristal alta velocidad) entre D+ y GND, y entre D- y GND (recortan a 3.6V)
- Pin GND del Arduino -> Cable GND (Negro del USB PC)
- Cable VBUS 5V (Rojo del USB PC) -> ¡NO CONECTAR! (Cortar y aislar para evitar conflicto con el móvil)

CONEXIÓN DEL ARDUINO AL TELÉFONO ANDROID:
- Conecte el puerto USB estándar del Arduino al teléfono Android mediante un cable/adaptador USB OTG.
- La aplicación "Teclado BIOS Arduino" detectará automáticamente el chip serial (CH340, CP2102, FTDI o Atmega16U2)
  a 9600 baudios, 8N1.

CÓMO FLASHEAR EL ARCHIVO .HEX EN EL ARDUINO:
Opción A: Desde la PC con Avrdude:
  avrdude -v -patmega328p -carduino -P /dev/ttyUSB0 -b 115200 -D -U flash:w:arduino_bios_keyboard_v1.hex:i

Opción B: Desde Arduino IDE:
  Abra arduino_bios_keyboard_v2.ino y presione "Subir" (Upload) en el puerto correspondiente.
