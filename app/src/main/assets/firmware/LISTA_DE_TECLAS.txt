======================================================================
     GUIA DE COMANDOS Y LISTA DE TECLAS - ARDUINO USB KEYBOARD + MOUSE
======================================================================

Velocidad de puerto serie recomendada: 9600 baudios (8-N-1)
Aplicacion recomendada: Serial USB Terminal (Android) o App Dedicada

----------------------------------------------------------------------
1. COMANDOS DE PROTOCOLO Y CONTROL (Prefijo '#')
----------------------------------------------------------------------
  #PING      Sincronizacion bidireccional (Responde: #PONG:BIOS_KEYBOARD_V2:LINK=...,PKTS=...)
  #SYNC      Alias de #PING
  #STATUS    Estado maquina (Responde: #STAT:LINK=1,ADDR=X,CFG=Y,PKTS=Z o #STAT:LINK=0)
  #TEXTO     Cambia al MODO TEXTO COMPLETO (Escribe libremente)
  #BIOS      Cambia al MODO BIOS RAPIDO (1 sola letra por accion)
  #AYUDA     Muestra el menu de ayuda en la pantalla
  #TEST      Ejecuta el test electrico de pines D2 y D4 (Hardware)
  #RESET     Fuerza un reinicio electrico del bus USB (SE0) hacia la PC
  ?          Consulta el estado de conexion USB con la PC/BIOS (Legible)


----------------------------------------------------------------------
2. EMULACION DE RATON / MOUSE HID (Version 2.0)
----------------------------------------------------------------------
Dispositivo USB compuesto que incluye raton estandar de 3 botones + rueda:

  Comando     Accion                                 Ejemplo / Uso
  ---------   ------------------------------------   ---------------------------
  #M:dx,dy    Mover cursor relativo (X, Y)          #M:20,-10  (Der 20, Arriba 10)
  #ML         Clic izquierdo (Left Click)            Abrir opciones / Setup UEFI
  #MR         Clic derecho (Right Click)             Menu contextual
  #MM         Clic central (Middle Click)            Boton de la rueda
  #MB:n       Clic en boton n (1=Izq, 2=Der, 4=Med) #MB:1
  #MD:btn     Boton presionado (Down / Iniciar Drag) #MD:1 o #MD:L
  #MU:btn     Boton liberado (Up / Soltar Drag)      #MU:1 o #MU (suelta todo)
  #MW:dz      Rueda de desplazamiento (Scroll)       #MW:2 (arriba), #MW:-2 (abajo)


----------------------------------------------------------------------
3. MODO TEXTO COMPLETO (Version 1.0 y 2.0)
----------------------------------------------------------------------
En este modo puedes escribir cualquier texto como en un teclado real:
  - Letras minusculas: a, b, c, ... z
  - Letras mayusculas: A, B, C, ... Z (envia Shift automaticamente)
  - Numeros:           0, 1, 2, ... 9
  - Espacio:           Barra espaciadora (' ')
  - Salto de linea:    Tecla Enter ('\n' o '\r', con antirrebote)
  - Simbolos:          ! @ # $ % ^ & * ( ) _ + { } | : " < > ?
                       - = [ ] \ ; ' , . / ` ~

TECLAS ESPECIALES (Escribir entre corchetes [ ... ]):
  [F1] a [F12]       Teclas de funcion F1 hasta F12
                     Nota: [F2], [F11] y [F12] llevan rafaga para POST

  [UP] o [ARRIBA]    Flecha Arriba (1 paso limpio, debounced)
  [DOWN] o [ABAJO]   Flecha Abajo (1 paso limpio, debounced)
  [LEFT] o [IZQ]     Flecha Izquierda (1 paso limpio, debounced)
  [RIGHT] o [DER]    Flecha Derecha (1 paso limpio, debounced)

  [ENTER] o [ENTRAR] Tecla Enter (1 pulsacion limpia - antirrebote 80ms)
  [ESC] o [ESCAPE]   Tecla Escape (Volver atras)
  [DEL] o [SUPR]     Tecla Suprimir (Rafaga para entrar a BIOS)
  [BS]               Tecla Retroceso (Borrar hacia atras)
  [TAB]              Tecla Tabulador
  [SPACE]            Barra espaciadora

  [HOME] o [INICIO]  Tecla Inicio
  [END] o [FIN]      Tecla Fin
  [PGUP] o [REPAG]   Re Pag (Subir pagina)
  [PGDN] o [AVPAG]   Av Pag (Bajar pagina)
  [INS]              Tecla Insert
  [PRTSC]            Imprimir Pantalla
  [CAPS]             Bloq Mayusculas
  [WIN] o [GUI]      Tecla Windows

ATAJOS COMBINADOS:
  [CAD]              Ctrl + Alt + Supr (Reiniciar equipo)
  [ALT+F4]           Cerrar ventana / Apagar
  [CTRL+C]           Copiar / Interrumpir proceso en consola
  [CTRL+V]           Pegar
  [CTRL+Z]           Deshacer
  [CTRL+A]           Seleccionar todo
  [CTRL+X]           Cortar


----------------------------------------------------------------------
4. MODO BIOS RAPIDO (Para botones Macro M1 a M6 en Serial USB Terminal)
----------------------------------------------------------------------
Activalo escribiendo #BIOS. Cada caracter ejecuta una accion directa:

  Tecla   Accion enviada      Uso tipico en BIOS
  -----   -----------------   ----------------------------------------
    s     SUPR (Rafaga)       Entrar a la BIOS en el arranque (POST)
    2     F2 (Rafaga)         Entrar a la BIOS (Asus, Dell, Acer, Lenovo)
    f     F11 (Rafaga)        Menu de arranque / Boot Menu
    b     F12 (Rafaga)        Menu de arranque alternativo
    0     F10 (1 toque)       Guardar cambios y salir de la BIOS
    u     Flecha Arriba       Mover seleccion arriba (1 paso)
    d     Flecha Abajo        Mover seleccion abajo (1 paso)
    l     Flecha Izquierda    Mover pestaña a la izquierda
    r     Flecha Derecha      Mover pestaña a la derecha
    e     ENTER (1 toque)     Abrir menu / Desplegar idioma / Confirmar
    x     ESC (1 toque)       Salir de submenu / Cancelar
    +     Tecla +             Aumentar valor / Cambiar idioma
    -     Tecla -             Disminuir valor / Cambiar idioma
  (esp)   Espacio             Alternar opcion / Marcar casilla


----------------------------------------------------------------------
5. CONFIGURACION RECOMENDADA DE BOTONES MACRO (M1 a M6)
----------------------------------------------------------------------
En Serial USB Terminal -> Menu -> Buttons:
  Boton M1: Nombre = "SUPR"    Texto = s     (o [DEL])
  Boton M2: Nombre = "ENTER"   Texto = e     (o [ENTER])
  Boton M3: Nombre = "ARRIBA"  Texto = u     (o [UP])
  Boton M4: Nombre = "ABAJO"   Texto = d     (o [DOWN])
  Boton M5: Nombre = "ESC"     Texto = x     (o [ESC])
  Boton M6: Nombre = "F10"     Texto = 0     (o [F10])
